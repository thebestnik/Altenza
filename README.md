# Altenza Visa Services

> Official Visa Advisory, Relocation Guidance & Commercial Entity Registration for Albania

**Altenza** is a modern, responsive web portal providing complete information, regulatory guidance, and procedural roadmaps for foreign entrepreneurs, investors, remote professionals, and families relocating to the Republic of Albania.

---

## 🌟 Key Features

- **Pure Glassmorphism Top Navigation**: Dynamic contrast-adaptive glass header that intelligently shifts between dark and light modes depending on scroll position.
- **Hero Route Finder**: Fast, non-reload qualification widget (`I am`, `Moving for`, `Timeline`, `Check Visa Options`) for instant route mapping.
- **Interactive 3D Passport & Permit Card**: Mouse-reactive 3D card with tilt tracking, specular light highlights, and spin animation.
- **Live Style & Color Customizer Dock**:
  - **10 Luxury Color Themes**:
    - *Rose Gold Group*: Rose Gold (Default), Champagne Sand, Bronze Rose
    - *Brown Shades Group*: Mocha Brown, Amber Cognac, Hazelnut
    - *Bright Colors Group*: Adriatic Azure, Sunset Coral, Emerald Jade, Royal Ruby
  - **Dynamic Logo Color Synchronization**: The Altenza 3D ribbon logo instantly updates across the header, interactive card, and footer to match the active theme.
  - **Modern Font Switcher**: Inter, Poppins, Plus Jakarta Sans, and Outfit.
- **Client Success Stories & Milestone Gallery**:
  - *Option 1*: **Modern Editorial (Mocha)** - Minimalist luxury cards featuring Tirana Skanderbeg, Sarandë Riviera, and Durrës Adriatic backdrops with sample Single Permit specimens.
  - *Option 2*: **Consular Posters** - Celebratory consular approval designs with landmark monuments.
  - *Option 3*: **Milestone Summary Cards** - Real-time HTML cards with verified badges and corridor routes.
- **Zero Build Step**: Standalone vanilla HTML5, CSS3, and modern JavaScript—no node_modules or bundlers required.

## 🚀 Making the Site Live via GitHub Pages (1-Click)

To make this site live immediately on GitHub Pages:

1. Open your repository on GitHub: [https://github.com/thebestnik/Altenza](https://github.com/thebestnik/Altenza)
2. Go to **Settings** > **Pages** (in the left sidebar).
3. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`
   - **Branch**: Select `main` and folder `/ (root)`
   - Click **Save**.
4. In approximately 60 seconds, your site will be live at:
   ```
   https://thebestnik.github.io/Altenza/
   ```
